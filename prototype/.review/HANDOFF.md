4. 頁面、結果訊息、信件主旨與內文全部使用 MM/DD。日期計算、紀錄與原生日期欄位保留 ISO；房間今天標示也依本次格式要求顯示 11/15。
5. 部分提前轉交的未領餘量可改期。原紀錄保留已收到的件數、起日、歸還日及狀態；改期餘量以關聯的新預約記錄，留下拆分及修改事件。庫存只排除舊的未領部分，仍計入自己手上的件數。林怡君的 `r19` 套圈圈為示範：原約 11/18 開始，11/15 已收到 1 件，另有 1 件可在我的借用修改。

## 前輪差異 1–11（保留的行為）

1. `RoomOrbit` 在原本的傳統腳本中處理滑鼠及單指拖曳、滾輪、雙指距離。俯仰限制為 0.18–1.4 弧度，縮放限制為 0.7–1.6；無平移、無額外重設按鈕。移動超過 5px 或使用兩指後不執行選取。單次點擊仍由目前相機 raycast，HTML 標籤仍每幀投影；選取時相機移向目標，保留使用者角度及縮放。
2. `remaining()` 與圖片遮罩共同使用 `outToday()`：已領取未歸還，加上原預約窗口中今天待領取的件數。公開清單對部分轉交者分開顯示已領取與待領取日期。
3. `#/reschedule/<record>` 可修改尚未領取預約的起日、結束日及件數，包含已到／過起日而仍待領取者；本輪也支援部分轉交後的餘量。庫存只排除自己的未領預約，缺貨或無效日期會停用儲存並顯示上限。儲存會留下前後值、顯示新值並產生「改期確認信」。
4. `#/mine` 顯示申請人的「延長申請中」、新歸還日及未回覆姓名；受影響者看到「待你回覆」及同意／不同意，呼叫與信件相同的方法。起始資料中，林怡君的情緒圖卡借用 `r1` 是申請人；語言理解桌遊預約 `r24` 是吳承翰借用 `r11` 的受影響者。公開房間仍不顯示任何待回覆狀態。
5. 全數同意後順延受影響預約起日、保留結束日。若新歸還日等於或晚於預約結束日，保留其原日期並允許至結束日（含當日）領取／自行改期；仍未領取時，隔日早間排程自動結束並寄出說明此例外的草稿信。改期後重新計算受影響者；不再受影響者免回覆，全部同意或免回覆即生效並寄信。
6. 逾期借用只在今天占用現場庫存；計算未來日期時視為已在原歸還日歸還，與今日剩餘量分開處理。
7. 延長跨越預約結束日的例外依第 5 點處理，不產生起日晚於結束日的無效期間。
8. `reservationStart` 保留未轉交餘量的原預約起日；已轉交部分的領取事件使用各自確認當日。餘量的領取窗口與取消期限仍為原起日加一天，不隨提前轉交變動。
9. 同一借用再送一次延長會把舊待回覆申請標記作廢，保留紀錄，重新計算並向新申請的受影響者寄信。我的借用仍能再次進入申請表，提示舊申請會被取代；舊信按鈕不會影響新申請。
10. 尚未回覆的預約者取消預約後，同樣重新計算並移除回覆義務。變動過程保留事件及舊回覆資料。
11. 已刪除 `prototype/DESIGN.md`；保留 `.review/` 供開發檢查。根目錄設計文件不在本任務寫入範圍。

直接開啟 `index.html`。執行檔是依序載入的傳統腳本。正常使用不需伺服器；外部字型、3D 與 QR 程式仍需連網。所有變動重新整理後歸零。

## 瀏覽器驗證限制

較早輪次曾用 `Start-Process -WindowStyle Hidden` 嘗試目前安裝的 Chrome 151、Chromium headless shell 1243 與 Chromium 1181，各自使用臨時測試設定目錄。本輪沒有再次啟動瀏覽器，也沒有請求提高權限、安裝套件或停用整個瀏覽器沙箱。

Chrome 151 的 CDP 連線能建立，但連空白頁的 Runtime 指令都沒有回應。headless shell 1243 的 GPU 程序以 `-1073741515` 結束。Chromium 1181 使用 `--disable-gpu` 後，仍因 GPU／網路程序存取失敗而結束（包含 `-1073741790`）。讀取程序命令列的 `Get-CimInstance` 亦遭拒絕存取。後續 `node prototype/.review/verify.cjs --capture` 回傳 `TypeError: fetch failed`，因測試瀏覽器已停止。

前輪 worker 執行 `node prototype/.review/verify.cjs --capture` 曾因 CDP 無法連線而失敗。根據本輪委派資訊，Claude 之後已在實際 headless Chromium 執行完整腳本，除鍵盤案例外皆通過，並提供目前 `.review/` 的截圖。本輪 worker 已讀取其中桌面及 390px 手機截圖，依六項指派修正，但沒有自行重跑瀏覽器，也沒有覆寫那些 PNG。

修正後的 3D 視覺、手機配置與原生鍵盤案例仍由 Claude 重跑驗證。`.review/verify.cjs` 已補上手機圓形／點擊框、借用列與部分改期情境，並修正 A1 原生按鈕前置條件。前輪由 Claude 回報的結果與本輪 47 組 Node 測試各自有其範圍，本報告不是 Claude 的獨立驗收。
