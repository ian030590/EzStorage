# 財產編號規則參考

以下是 EzStorage 的自訂規則範例，不是政府或機構的官方財產分類標準。有既有財編時，直接沿用原編號即可；系統不強制套用本範例。

建議格式：`單位-類別-取得西元年-流水號`，例如 `REH-TEACH-2026-0001`。

| 欄位 | 範例 | 建議 |
| --- | --- | --- |
| 單位 | `REH` | 固定使用同一組單位縮寫 |
| 類別 | `TEACH`、`EQUIP`、`FURN` | 教具、設備、家具；由單位自行定義 |
| 取得年份 | `2026` | 使用四位西元年，避免與民國年混淆 |
| 流水號 | `0001` | 同單位、類別、年份內遞增，不重複使用報廢編號 |

- 財產編號代表資產身分；物品搬房間、換櫃子或改名稱時保持不變。
- 位置編號用來找位置，例如 `A1-2-01`；移動後可變更，不能拿它當財編。
- QR Code 綁定物品的固定 ID，不綁房間名稱、位置編號或財編，移動後原標籤仍可用。
- 財編可留空；填寫時須保持唯一，修改或清空也不會改動歷史借還紀錄。
- 現行一筆物品可有多件庫存，其財編是該筆物品的編號。若每件實體都有不同的正式財編，請每件建立一筆物品、總件數填 1；避免把不同財編合成同一筆庫存。
- 外部正式財產系統仍是正式財編來源；本系統提供借還與位置管理，不自動認定資產分類或折舊。
